# 🤖 AI-Based Resume Screening System

An AI-powered resume screening and candidate ranking system that uses Natural Language Processing (NLP) and transformer-based embeddings to match resumes with job descriptions.

## 📌 Project Overview

Recruiters often need to screen a large number of resumes for a single job opening. Traditional keyword-based screening can miss candidates whose resumes use different terminology to describe similar skills.

This project addresses the problem using semantic similarity and AI-based ranking.

The system:

- 📄 Extracts text from resumes and job descriptions
- 🧹 Preprocesses the extracted text
- 🧠 Generates transformer-based embeddings
- 🔍 Calculates semantic similarity
- 📊 Ranks candidates based on relevance
- 💡 Provides explainable insights
- 🌐 Provides an interactive web interface

## ✨ Key Features

### Resume Processing
Upload multiple resumes and automatically extract their textual content.

### Job Description Analysis
Provide a job description containing required skills, qualifications and experience.

### Semantic Matching
Uses transformer embeddings to identify semantic relationships between the resume and job description.

### Candidate Ranking
Candidates are ranked according to their calculated match scores.

### Explainable AI
The system highlights:

- Matched skills
- Missing skills
- Relevant experience
- Important matching evidence

### Interactive Dashboard
A Streamlit interface provides an easy way to upload documents and view screening results.
